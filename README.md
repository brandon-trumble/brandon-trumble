### About Me

I'm a developer based in **Ontario, Canada**, studying at **Georgian College** and working as a **Full Stack Engineer at Young Drivers of Canada**.

Most of my time goes into backend architecture, APIs, databases, and figuring out why something that “should be fast” is making twelve database calls.

My main focus is **Java + Spring Boot**, building practical services and exploring concurrency, caching, security, and clean architecture. I also enjoy **Go** for straightforward backend services and **Rust** for systems programming and productive disagreements with the borrow checker.

**The goal:** build software that stays fast, understandable, and reliable when real people start using it.

### Currently Building

**[ListWright](https://listwrightco.com)** — a tool that helps sellers create and publish marketplace listings.

I'm migrating its Go backend to **Java + Spring Boot**, working through:

- Etsy publishing and planned marketplace integrations.

Real product. Real engineering decisions. Plenty of opportunities to ask, “Could this just be one SQL query?”

### How I Like to Build

- Keep controllers thin and business logic testable.
- Measure performance before declaring victory.
- Let the database do what databases are good at.
- Make failures useful to debug.
- Write code that future me can understand before his first coffee.

### The Development Cycle

1. Write the code.
2. Run the code.
3. Read the stack trace.
4. Realize the configuration was wrong.
5. Make coffee.
